# 🐾 Pokemon Viewer

A simple and interactive Pokemon Viewer built using **HTML, CSS, and JavaScript**. The application allows users to view Pokemon information by fetching data from the **PokeAPI**.

## 📌 Features

* 🔍 Search and view Pokemon
* 🐾 Display Pokemon name
* 🖼️ Display Pokemon image
* ⚡ Display Pokemon type
* 📊 Display Pokemon details
* 🌐 Fetch data from an external API
* 🖥️ Clean and responsive user interface
* ⚡ Interactive user experience

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and API integration
* **PokeAPI** – Pokemon data

## 📂 Project Structure

```text
Pokemon-Viewer/
│
├── index.html
├── style.css
└── script.js
```

## ⚙️ How It Works

The application uses the **PokeAPI** to retrieve Pokemon information.

### 🔍 Search Pokemon

The user can enter a Pokemon name or number to search for a Pokemon.

### 🐾 Pokemon Information

The application displays available information such as:

* Pokemon name
* Pokemon image
* Pokemon type
* Pokemon details

### 🌐 API Integration

JavaScript sends a request to the PokeAPI and processes the returned JSON data to display the Pokemon information dynamically.

## 🚀 How to Run

1. Clone the repository:

git clone https://github.com/deshmukhdnyaneshwar/Pokemon-Viewer.git

2. Open the project folder.

3. Open `index.html` in a web browser.

4. Enter a Pokemon name or number to view its information.
